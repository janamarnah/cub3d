# cub3D

## Description
cub3D is a mandatory-only ray-casting project written in C with MiniLibX. It renders
a first-person view of a maze using four wall textures and floor/ceiling colors.

## Instructions
Place the Linux MiniLibX sources in `minilibx-linux/`, then run:

    make
    ./cub3D maps/valid.cub

Controls: W/A/S/D move, left/right arrows rotate, ESC exits. Closing the window also
exits cleanly.
